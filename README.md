# VC Tools

The official website for VC Tools, an upcoming Windows app designed to make managing your Roblox friends list easier.

[Visit the website](https://ryanw506.github.io/Vc-Tools/)

## About

VC Tools is in development. The website introduces the project and explains how the desktop app will be downloaded and opened when a release is available. The friend list shown on the site is an illustration with fictional names.

The desktop app, account connection, and download are not yet available. This repository currently contains the website only.

## Website

- English by default, with an Arabic language option
- Responsive layout for desktop and mobile
- Built with HTML, CSS, and JavaScript

To preview it locally, open `index.html` in your browser. The website is published with GitHub Pages.
